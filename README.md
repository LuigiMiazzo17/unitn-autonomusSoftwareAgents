# Autonomous Software Agents

This is the repository for the "Autonomus Software Agents" Project @ UniTn A.A.
2024/2025, Prof. Giorgini Paolo.

It involves the development of both single-agent and multi-agent system that
simulates the behavior of autonomous agents in a software environment.
